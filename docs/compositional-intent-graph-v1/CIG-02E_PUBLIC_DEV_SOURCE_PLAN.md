# CIG-02E source-separated public DEV sourcing plan

The next CIG-02 development fixture must use natural expressions written independently of the CIG public Catalog/Profile/frame authors. The current 144-Topic runtime remains unscored engineering. This checkpoint first examines one candidate source: Databricks Dolly 15k instructions, mirrored publicly at `buayism/dolly-15k-dataset`, Git commit `6d7ebf384c5e588ee1b0dff816557489bc16089c`, file `databricks-dolly-15k.jsonl`, Git blob `7c507d16b055ae32107a6dd0585779678565dcd2`. The mirror README describes independently human-written English instructions by Databricks employees and declares CC BY-SA 3.0. The audit uses GitHub-hosted bytes pinned to that commit and verifies the blob before reading.

The source inventory performs only English lexical retrieval against the public formal names and lexical anchors for all 144 Topics. It records candidate counts and zero-hit Topic IDs. A lexical hit is **not** a gold label, a fixture row, a router result, or coverage evidence. Zero hits do not prove a Topic is absent semantically. The script never loads the CIG-02E router or any consumed DEV/TEST and does not open a new capability TEST. No corpus text is copied into this repository by the audit.

The first exact-head source inventory (Actions run `36094769089`, head `1c5344823b675cc8523a6436eee670b14f5d78b2`) read 15,011 Dolly instruction rows and found lexical candidates for 131/144 Topics; 13 Topics had none. This is a retrieval limit, not a gold or capability result. A second source-only inventory now checks Stanford Alpaca public synthetic instructions at `tatsu-lab/stanford_alpaca`, commit `761dc5bfbdeeffa89b8bff5d038781a4055f796a`, file `alpaca_data.json`, Git blob `3779ddbc040543ab1834ef216c983d6fcc06cc9a`. Its datasheet describes model-generated instructions and its data license declares CC BY-NC 4.0. It is supplemental synthetic source evidence, clearly distinct from human-authored Dolly; no model is called by this audit. No corpus text is copied into this repository.

After reviewing both source-only inventories, determine whether the sources can supply independently written, adjudicable requests for every Topic plus ambiguous and insufficient-evidence controls. If not, record the gap and add a separately sourced public corpus before fixture construction. Then freeze candidate, fixture, gold, scorer and hashes **before** the first scored DEV run. Score only that new public DEV under the original 0.95 assigned precision, 0.70 coverage, 0.70 Topic macro recall, at most 0.02 insufficient-evidence false assignment and zero context-harm floors. CIG-02 remains unfrozen; CIG-03 independent capability TEST remains blocked and owner controlled.
