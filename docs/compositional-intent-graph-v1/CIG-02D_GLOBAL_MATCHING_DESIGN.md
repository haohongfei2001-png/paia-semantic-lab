# CIG-02D global request and typed evidence design

## Evidence and bounded hypothesis

The source-separated CIG-02C CLINC `train` DEV assigned 3/110 requests. A post-score aggregate diagnostic found the frozen global action cue in 17/110, any indexed object anchor in 59/110, and both in 12/110. These counts justify testing two **global** mechanisms: broader request-form detection and more tolerant matching of existing public profile atoms. They do not justify adding the observed utterances as aliases, adjusting a threshold to pass that slice, or claiming a full-Catalog limit.

## Candidate within the frozen product boundary

The shipped path remains zero-model, deterministic, offline, local-first and small. Build inputs remain the public formal Catalog and public derived profiles only; CLINC is development evidence, never a lexicon source. Every Topic remains eligible. The current explicit GOAL span still takes precedence over means/background. The extension may:

1. recognize globally specified question, imperative and request forms in English and Chinese, with DEFER on mere mentions, quotation and multi-goal conflict;
2. normalize punctuation and simple inflection uniformly across the 144 Topic atoms;
3. add a bounded token/character overlap score from existing typed OBJECT and OUTCOME atoms, weighted by cross-Topic distinctiveness and requiring a fixed global margin;
4. retain provenance for all evidence and expose why assignment was permitted.

No per-Topic exception, hidden domain prior, neural asset, semantic API, private artifact or PAIA production read/write is allowed. The original index <= 1 MiB, router plus index <= 2 MiB, incremental memory <= 32 MiB, warm p95 <= 20 ms and cold <= 100 ms limits remain unchanged.

## Development protocol

Freeze the candidate, two global policy choices, selection rule and scorer before opening a **new** public DEV. The already scored CLINC selection is consumed; it may be used only for the aggregate failure attribution above. A possible narrow source-separated DEV is a disjoint deterministic selection of ranks 10-19 from the same pinned CLINC `train` split, with the unchanged conservative eleven-label mapping. Because it represents only eleven Topics in English, any result is development evidence, never 144-Topic capability certification. Report assigned precision, coverage, represented-Topic macro recall, wrong assignments, DEFER safety on a separately authored public control stratum, context harm, deterministic repeat and footprint. A full-Catalog, independently authored public DEV is still needed before any CIG-02 freeze; CIG-03 remains blocked until then.

If a global mechanism cannot materially improve source-separated coverage without unsafe assignments, record a genuine CIG-02 failure class. Do not lower the 0.95/0.70/0.70/0.02/zero-harm capability gates or relabel a DEV as the independent capability TEST.
