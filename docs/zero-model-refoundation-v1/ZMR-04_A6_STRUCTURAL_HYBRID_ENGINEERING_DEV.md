# ZMR-04 A6 bounded structural hybrid engineering

This batch implements one **development-only** A6 mechanism hypothesis: an A3 character sparse scorer evaluates the complete original input across all 144 Topics; the A5 diagnostic parser may identify exactly one nonquoted, unnegated goal span. That goal span is scored by the same full144 A3 index at a stricter fixed score/margin. If both views assign different Topics, A6 returns `DEFER` with a conflict reason. If the full-input view defers for low/ambiguous evidence and the focused view clears the stricter threshold, A6 may assign the focused Topic. Otherwise the exact full-input result remains the fallback. No domain/Topic mask, hard span deletion, second index, neural asset or semantic API is used.

The hypothesis is that bounded goal evidence could recover some cases the bag scorer defers while explicit disagreement avoids over-assignment. It is **untested on semantic data** and may fail by parser coverage cliffs, false goal cues, a lost object or assignment from too little context. The parser is a heuristic, not gold. The fixed engineering defaults are full score/margin `0.02/0.02` and focused goal `0.08/0.05`; they are not calibrated. The deletion ablation is the unchanged A3 full-input scorer. Further ablations must compare no focused stage and conflict-only stage on a fresh registered public cohort, including natural non-template examples and the frozen role/scope mechanism slice.

Five synthetic-index engineering tests cover unchanged full-input fallback, disagreement DEFER, focused supplementation, invalid index/Catalog/config fail closed, and quote/negation nonactivation. These tests do not establish semantic precision or coverage. A deterministic public TRAIN v0.2 A3-char build produced a 114,123-byte index; A1+A3+A5+A6 runtime source totaled 21,112 bytes, or 135,235 bytes together. This is a static engineering observation under the 1 MiB/2 MiB byte caps, **not** browser memory, latency, cold start, capability or resource PASS.

The candidate is not stable or promoted. Next freeze a fresh public full144 single-label cohort and broaden safety layers, register the complete changed closure, fixed configurations and evaluation key, then score once. The 18-row role packet remains UNRUN until that comparison and is only a non-independent mechanism slice. The independent ZMR-01B gate remains `NOT_QUALIFIED`, capability `UNTESTED`, resources `NOT_QUALIFIED`; all product constraints and TEST boundaries remain intact.
