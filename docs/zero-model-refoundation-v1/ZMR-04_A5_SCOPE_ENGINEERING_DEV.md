# ZMR-04 A5 role/scope diagnostic engineering

The A5 prototype is a bounded, deterministic **diagnostic parser**, not a Router candidate or a label oracle. It receives product-shaped `current/title/recent` input but analyzes only `current`; it returns UTF-16 source offsets for candidate action, object/background, goal and qualifier spans, plus negation, correction and quotation cues. Every role remains a hypothesis. It makes no Topic decision and always retains the complete original `current` for a future full144 fallback. A quoted action cue is recorded as quoted and not promoted into an action span; a correction records both the replaced and current candidate spans instead of deleting one.

The finite cue list is handwritten and bilingual. It is intentionally incomplete and can misread natural paraphrases, cross-clause corrections, nested or malformed quotations and multilingual word boundaries. An unbalanced quote is marked; bad inputs and inputs above the 8192 Unicode-scalar **research measurement profile** are unparsed with a diagnostic status, not truncated. This profile is not a PAIA product input limit. No runtime classifier, index, CAL, AS, final TEST, private archive or production PAIA code is touched.

Three focused engineering tests cover role offsets, correction/quotation preservation, title/recent noninterference, and bad or over-profile input. Their PASS is only an engineering observation. Before any A5 scoring, freeze a fresh public same-writer role/scope challenge with natural paraphrases, action/object/goal/qualifier changes, negation and correction, quotes, and ambiguity controls. Keep source and lineage explicit and mark all rows `NON_INDEPENDENT_DEVELOPMENT_EVIDENCE`. Compare actual end-to-end full144 Router output with parser deletion and full-input fallback ablations; do not use an oracle role score as capability evidence.
