# ZMR-03 public provisional safety seed

This coherent intake adds `provisional_safety_seed_v0.1.json`: 12 insufficient-evidence controls, six context-required scenario pairs, six context-invariance pairs, and 12 provisional two-intent scenarios. The context variant stays inside the same scenario/lineage component; it is not a second independent base case. The controls are balanced four zh, four en and four mixed; the paired and multi layers also contain all three language tags. All labels and boundary choices are provisional and were written by the same candidate writer after seeing A1/A2 diagnostics and the A3 implementation. `evaluation_status=UNRUN` and qualification credit is zero.

Each row carries the pinned Catalog digest, source/license declaration, writer cohort, scenario/template family, exposure, mechanism, input bundle and provisional label. Row IDs and scenario families are unique. A mechanical bundle-hash screen found zero exact overlaps with existing public TRAIN/TUNE/CAL/challenge files; this is not proof of semantic or lineage independence. There is no independent author, curator, reviewer, source audit or blind storage. Some boundary choices, especially whether related goals are two Topics and whether short requests should DEFER, require independent adjudication before use as gold.

The seed is deliberately smaller than DATA_PROTOCOL qualification minima: ordinary/challenge data require at least 300 controls, 144 context-required pairs, 144 context-invariance/conflict pairs and 144 multi-intent cases, with independent cohorts and review. The six invariance pairs do not yet cover the full conflict matrix. This set supports development of evaluator and Router handling only; no candidate predictions or safety scores were produced. It cannot arm AS, establish capability or resource PASS, or reduce the fixed control false-assignment/global precision/context gates. Next work is to broaden high-quality public safety mechanisms and create a fresh public full144 single-label challenge before registering any A3 comparison.
