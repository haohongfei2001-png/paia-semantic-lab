# ZMR-05 C1 repair 1: source-separated continuation and goal splitting

The fixed C1 v0.5 public diagnostic rejected both character and word configurations: context-required exact was 0/12, explicit multi-intent exact was at most 2/12, and the A3 character anchor assigned seven of twelve controls. Those are aggregate same-writer observations; no consumed row, AS, or TEST content was used to design this repair. This is the first of at most two C1 mechanism repair slots, with **no new semantic evaluation yet**.

The new `c1_r1_context_multi.mjs` is a separate immutable closure from the consumed C1 comparator. It expands a bounded, explicit continuation grammar and scores the last recent message alone as a second source-separated hypothesis. The existing recent-plus-current hypothesis remains; if both assign different Topics, the result is DEFER. A current-only assignment that conflicts with the supported context also DEFERs. A self-contained current request outside the explicit continuation grammar returns the complete A3 output unchanged. Title never supplies independent Topic evidence. This may recover a continuation when joining filler words to a recent message dilutes A3 scoring, but the synthetic tests do not establish natural context recall or safety.

The explicit two-goal parser now finds one bounded coordination marker across Chinese and English forms, rather than requiring one punctuation pattern. It rejects more than one marker and requires each resulting current span to pass the full144 A3 scorer separately with distinct Topics. Quoted material is not split. No top-k guessing, Topic mask, model, embedding, LLM, semantic API or extra runtime dependency is introduced. The unchanged 8,192-scalar/32-recent-entry limit is a development measurement profile.

Five synthetic-index tests cover self-contained invariance, last-recent continuation, source conflict, independent two-goal support and fail-closed inputs. This is `NON_INDEPENDENT_DEVELOPMENT_EVIDENCE` and does not remedy the observed unsafe A3 controls. The old C1 source and its consumed v0.5 registration/result remain unchanged for audit. C1-R1 is `ENGINEERING_ONLY_UNRUN`; it is neither stable nor promoted. ZMR-01B stays `NOT_QUALIFIED`, capability `UNTESTED`, resources `NOT_QUALIFIED`.
