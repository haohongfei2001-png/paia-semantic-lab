# ZMR-05 A4 bounded pairwise negative-evidence veto — engineering

A4 now has a development-only finite pair mechanism compiled from the pinned 144-Topic Catalog, Catalog-derived provisional boundary graph and fresh designated public A4 TRAIN v0.1. The base scorer remains the earlier full144 A3 char index from TRAIN v0.2. The compiler has fixed paths and rejects symlinks; it never reads challenge, DEV, AS, final TEST or the consumed CIG-v1 TEST. Ambiguous TRAIN examples have no gold and are used only to suppress shared lexical features, not to teach a DEFER label.

For each of four fixed graph pairs, the compiler retains at most 12 unique character n-grams from each of two left and two right TRAIN scenarios (at most 24 per side). It removes terms present on the opposite side or in the unresolved ambiguous case. The resulting feature lists, graph rank, Topic IDs and source digests are explicit and deterministic. The index has all 144 Topic IDs; the four pairs form a bounded review subset, never a reduced output universe.

The Router first calls unchanged full144 A3 on the original current text. If A3 DEFERs or assigns a Topic outside the four pairs, A4 returns that output exactly. When A3 assigns a member of a pair, A4 may only **veto to DEFER**: any lexical evidence on both pair sides is a conflict, and at least two opposite-side features are negative evidence. It never promotes a new Topic assignment or uses title/recent as independent evidence. Bad Catalog/index closure, unsupported configuration and invalid pair index fail closed. This mechanism tests whether a small contrastive negative-evidence stage can reduce mistaken assignments without silently switching labels. It may lose coverage, which a fresh paired evaluation must measure.

The fixed build reports a 9,743-byte pair index plus a 114,123-byte A3 char index: 123,866 total index bytes and 143,652 runtime-plus-index source bytes. These static counts fit the unchanged 1 MiB and 2 MiB caps. They are **not** production bundle, browser memory, warm p95 or cold-init measurements, so resource verdict remains `NOT_QUALIFIED`. One targeted engineering test covers deterministic source closure, full144 fallback, pair conflict/negative veto, fail-closed mismatches and static limits. The complete package suite has 79 tests after this batch.

No A4 semantic evaluation has been run since this mechanism was compiled. The consumed A4 triad v0.1 challenge must not be replayed. Next create a fresh public candidate-writer challenge with positive, negative, ambiguous and no-request controls, screen provenance/lineage/overlap, freeze it, then register one paired A3 versus A4 comparison and deletion ablation. A4 will be eliminated if vetoes remove correct assignments without an isolated safety-preserving gain. All current data is `NON_INDEPENDENT_DEVELOPMENT_EVIDENCE`, with zero independent quota, capability or saturation credit.
