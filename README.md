# PAIA Semantic Lab

Independent R&D repository for **PAIA semantic routing research**, not a standalone AI/NLP product and not a required PAIA production dependency. PAIA is a personal AI Input Archive for ordinary users: preserve and organize Inputs, retrieve them, organize Personal Topics and reuse context.

Read [PAIA_INTEGRATION_BOUNDARY.md](PAIA_INTEGRATION_BOUNDARY.md) for the current Lab-to-PAIA contract and [PAIA's canonical Personal Topic Architecture](https://github.com/haohongfei2001-png/paia/blob/main/extension/docs/consumer-product-v1/TOPIC_ARCHITECTURE.md) for the single product authority.
